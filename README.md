# PRCRMP_WaterQuality_2023-2025

CCRI_PRCRMP_Chemistry_Data_all_5-29-2025.xlsx contains the latest version of the water quality data sampled approximately quarterly from 2023 to 2025 for the Puerto Rico Coral Reef Monitoring Program sites.

This project contains individual project folders labeled for each of the sampling Quarters that merge the lab and field data for the respective sampling quarter and generate summary tables and plots (CCRI_QX). Each of these folder contains records of calibration logs and reports for the respective sampling quarter. Additionally, CCRI_Q1_Q2_Nutrients includes additional summary information for Quarters 1 and 2.

The Quality Assurance Project Plan and laboratory-specific Standard Operating Procedures are all contained in the Current QAPP + SOP folder.

The CCRI_QA_QC_all folder contains all the data and code used to calculate accuracy and precision for each parameter and generates summary tables and figure used in the primary data release paper.
